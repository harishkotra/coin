No text is generated

This model has no language head. It reads your text once and returns probabilities over answer codes. Zero output tokens, so there is no paragraph to talk you into an answer.

Three phrasings

The same question is asked three different ways. If the readings drift apart, the card says the number is unstable instead of hiding it.

An evidence check

A fourth pass scores how much checkable detail is actually in your text. A confident read on no evidence is still a guess, and it says so.
